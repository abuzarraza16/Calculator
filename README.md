# My Calculator

Hi! 👋

This is my calculator project, which I made for my Class 11 Computer assignment at Punjab College.

I made the design using HTML and CSS, and then used JavaScript to make the calculator work. This is one of my first web development projects, and I made it to learn how these three technologies work together.

## What can it do?

My calculator can perform these operations:

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Decimal numbers
- Clear all (AC)
- Delete the last digit (DEL)

It also supports keyboard input and shows an error when someone tries to divide by zero.

## Technologies I Used

- HTML for the structure
- CSS for the design and colours
- JavaScript for the calculations and button functions

## Project Files

My-Calculator/

## How to Run It

You don't need to install anything extra.

1. Download or clone this repository.
2. Put all the project files in the same folder.
3. Open `index.html` in your browser.
4. Start using the calculator.
